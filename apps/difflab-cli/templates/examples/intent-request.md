# Intent: Faster project search

## Objective

People with many projects need to find a project by name without scrolling through the full list. Keep the existing project list available.

## Context

Support has received requests from users with large project lists. We do not yet have a measured search-time baseline.

## Constraints

Search should work from the keyboard and should not reveal projects a user cannot access.

## Out of Scope

Searching tasks or users.

## Open Questions

Should results include archived projects by default?
