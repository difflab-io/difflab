# Intent: Faster project search

## Objective

People with many projects need to find a project by name without scrolling through the full list. Support has received requests about this, but we do not yet have a measured search-time baseline.

## Requirements/Instructions

- Let users search accessible projects by name while keeping the existing project list available.
- Do not add search for tasks or users.

## Constraints

Search must work from the keyboard and must not reveal projects a user cannot access.

## Open Questions

Should results include archived projects by default?
