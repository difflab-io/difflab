# GitHub capabilities

Use existing authenticated GitHub forge capabilities for pull request metadata, draft creation, ready transition, review ownership, review submission, merge, and workflow runs. Check permissions and repository settings before writes. Confirm whether a pull request already exists for the selected source and base.

A pending pull request review belongs to one account and can contain draft inline comments. Identify the authenticated user's pending review specifically; do not submit or alter another reviewer's comments. Review submission events distinguish approval, request changes, and comment. If there is no pending review, a disposition may still be submitted as a new review when the user requested that disposition; do not invent inline comments. Supply the user's overall comment verbatim when present; only add a minimal neutral body if the API requires a nonempty body. For request changes with no pending comments and no user message, ask for actionable feedback rather than manufacturing a reason. If the selected account cannot review its own PR or policy forbids approval, report the rejection.

Ready transition changes only the pull request draft state and leaves review drafts intact. Use the merge method permitted by branch rules; do not assume a squash commit or subject is valid for a release pipeline. After merging, identify the actual base branch and resulting base SHA. Match post-merge workflow runs to both that SHA and base ref and to the relevant trigger; pull-request validation often tests a synthetic pre-merge commit, not the merged base commit. Inspect check conclusions and failing-run logs. A run for an older base SHA does not establish the merged commit's status. See [merge](../workflows/merge.md).

Official references: [review submission](https://docs.github.com/en/rest/pulls/reviews), [pull requests](https://docs.github.com/en/rest/pulls/pulls), and [workflow runs](https://docs.github.com/en/rest/actions/workflow-runs). Recheck current behavior if the installed tooling or API response differs.
