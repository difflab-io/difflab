# `adr init`

Scaffold a blank record only. Do not decide, fill placeholders, add an index row, or change application code.

1. Confirm the absolute Git repository root. Read `adr/README.md` and `adr/template.md`; inspect direct children of `adr/` matching either `^[0-9]{4}-[a-z0-9]+(?:-[a-z0-9]+)*$` (directories, including reserved or incomplete ones) or the legacy flat `^[0-9]{4}-[a-z0-9]+(?:-[a-z0-9]+)*\.md$` (files). Check each numbered directory for `ADR.md` and any resources. Ignore `README.md`, `template.md`, and other files. If multiple entries share a number, or a numbered directory is incomplete, do not reuse that number; ask for guidance where it might represent this decision. Interpret the four-digit prefix as decimal. Allocate one more than the highest existing number (0001 if none); never fill gaps. If the next number exceeds 9999, stop and ask how to extend the convention.
2. Derive a short lower-case kebab-case title from the user's decision topic, not a guessed outcome. Check for an existing record or scaffold for the same decision, including a legacy flat file, a reserved directory, or one with a different number or title. If one clear draft exists, show it and ask whether to use `adr new` to fill it; if several plausible records exist, ask which to use. Do not create a duplicate. If no decision topic is provided, ask for one before scaffolding.
3. Preview `adr/NNNN-kebab-title/ADR.md`. Atomically reserve the _directory_ with a non-recursive, exclusive directory creation (e.g. `mkdir adr/NNNN-kebab-title` after confirming `adr/` is a real directory). Do not use `mkdir -p`: the MCP scaffold tool protects only the destination **file**, not a pre-existing directory or its resources. If the directory exists, even empty, or a flat file claims the number, do not enter or overwrite it. On a collision, re-list both layouts, check for the same decision again, then retry at the new maximum + 1 only if unambiguous; otherwise stop and ask. Once the directory is reserved, call MCP `scaffold({name:"architecture-decision-record",cwd:<absolute repository root>,path:"adr/NNNN-kebab-title",filename:"ADR.md"})`. The tool exclusively creates `ADR.md`. Never use direct writing, copying, or force as a fallback. If scaffolding fails, leave the reserved directory intact, report it, and do not silently retry or remove files (another writer may have added resources).
4. Read the scaffolded document to confirm it contains the expected decision headings and proposed status. If a customized installed template differs from `adr/template.md`, preserve its usable headings and flag any missing context/status sections for the user. Leave all placeholders for the user to complete. The README index remains unchanged until the record is authored.

For example, if `adr/0001-cache-policy.md` and `adr/0003-api-boundary/ADR.md` exist, “adr init queue ownership” scaffolds `adr/0004-queue-ownership/ADR.md`, not `0002`. Report the path and that it is only a scaffold.
