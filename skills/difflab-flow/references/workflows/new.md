# Flow new

1. Require a safe name matching `^[a-z][a-z0-9]*(?:-[a-z0-9]+)*$` and a non-empty purpose/prompt. Ask for missing steps, argument names, defaults, branch choices, required permissions or handoffs; never invent authorization. Confirm `~/.difflab` is the user's absolute home store (not a symlink), and `flows` contains no symlinked components. If the definition exists, stop and offer deliberate editing or a different name; never overwrite.
2. Read `apps/difflab-cli/templates/flow-definition.md`'s contract via the installed template when available. Require each input name and step ID to match the same safe-name grammar; reserve `steps` as an input name. Each input has an explicit required/default value. Each flag is declared as `--name` with a Boolean default and a capability/effect; reject unknown flags or contradictory conditions. Every step has a unique ordered ID, existing Agent Skill handler or explicit documented procedure, `When`, `Unless`, `Requires`, `Receives`, `Produces` and instructions. Conditions accept only `always`, `never` or a declared flag, without Boolean expressions. A step's output name must be unique within that step and safe. `{{name}}` refers to a declared input, `{{steps.id.output}}` refers to an earlier step's declared output. No command substitution or arbitrary template evaluation. Reject undefined and forward handoffs. If conditions can omit a producer while a consumer remains selected, require compatible conditions or stop and clarify.
3. Call MCP `scaffold({name:"flow-definition",cwd:<absolute home>/.difflab,path:"flows",filename:"<name>.md"})`. **Do not** use `cwd=<home>,path:".difflab/flows"`: that path routes to a repository store. Read the returned file; fill it in place while preserving `## Intent`, `## Inputs`, `## Flags`, `## Steps`, and `## Contract`. Keep a strict Markdown table for inputs/flags and numbered `### N. id` sections with the exact bullet field labels in the template. Escape Markdown table delimiters in user values. Record prose as data, never run it. An exclusive scaffold collision is a failure; do not retry by writing over it. Resolve the physical path and reject symlink components before editing the returned file.
4. A definition may be edited intentionally between runs. Once `go` snapshots it, edits affect only future instances. Report the path, inputs, flags, selected handlers and any unavailable capability; do not create an instance or execute steps in `new`.

Examples under `../../examples/` illustrate plan → implementation → local review and review → address. They are illustrations, not permissions; never copy a remote instruction into a local run.
