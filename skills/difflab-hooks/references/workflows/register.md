# Register a hook

1. Require a safe hook name matching `^[a-z][a-z0-9]*(?:-[a-z0-9]+)*$` (such as `on-merge`, `on-request-worktree`, or `on-remote-delegation`). If the name, trigger, or intended handler is unclear, inspect the active harness, environment variables, installed skills, local `--help` output, and current official documentation first, then present tailored choices alongside `default` and ask the user.
2. Make sure that `~/.difflab` is the physical home store of the user (not a symlink) and that `~/.difflab/hooks/<name>/HOOK.md` does not already exist. If `HOOK.md` exists, stop and offer deliberate editing or another name rather than overwriting it.
3. Call MCP `scaffold({name:"hook-definition",cwd:"<absolute home>/.difflab",path:"hooks/<name>",filename:"HOOK.md"})` (or `difflab templates scaffold hook-definition hooks/<name> HOOK.md --cwd <absolute home>/.difflab`). Do not pass `path:".difflab/hooks/<name>"` with `cwd=<home>`, which targets a repository store.
4. Read the scaffolded `HOOK.md` and fill `## Trigger`, `## Action` (`Handler`, `Requires`, `Receives`), and `## Instructions` concisely using [difflab-writing-style](../../../difflab-writing-style/SKILL.md):
   - For `on-request-worktree` with `Handler: default`, set `Receives` to `project_key, repo_slug, source_root, base_ref, branch_name, branch_slug, task_brief`. Record instructions to create `~/.difflab/worktrees/{{project_key}}/{{repo_slug}}/{{branch_slug}}` from `{{base_ref}}`, run `difflab init {{project_key}}`, and coordinate through native subagents in the active harness.
   - For `on-remote-delegation` with `Handler: default`, set `Receives` to `project_key, repo_origin, base_ref, branch_name, approved_files, automerge_rules, task_brief` and record delegating through the built-in background or remote capability of the active harness.
   - For a custom handler, research current official documentation or CLI `--help` output for the selected tool before writing concrete instructions into `HOOK.md`.
5. Report the created `~/.difflab/hooks/<name>/HOOK.md` path, trigger, and handler. Do not execute the hook during `register`.
